# Windows dotfiles

This repository mirrors the configs in the $HOME directory on my Windows machine. env.local and local.sh are used for overriding Windows default paths and adding machine-specific commands, respectively.

It contains configs both for my development environment and for my Tokyo Night-themed desktop environment.

Files under `.config/` exist in `%USERPROFILE%\.config`, and files under `AppData/Roaming/` exist in `%APPDATA%`. The rest go in `%USERPROFILE%` (aka `$HOME`).

## App-specific notes

### Komorebi
- For any config files generated by the installation that I have not provided here, assume that I have not edited them.
- I use workspace 1 as a sort of "communications hub" for Discord/Thunderbird, managed through workspace_rules.
- I do not use komorebi-bar, only YASB.
- I use AHK for my hotkeys, not whkd.
- As komorebi sometimes fails to pick up AHK on startup, I do not tie the startup of the komorebi.ahk script to komorebi startup.

#### Komorebi Hotkeys

- **Launch:** `Alt+W` Firefox; `Alt+Shift+A` YouTube in the configured Firefox container; `Alt+T` WezTerm.

- **Capture:** `Alt+E` Snipping Tool; `Alt+Shift+E` screen clip; `Alt+G` `Ctrl+PrintScreen`; `Alt+Shift+G` save a screenshot.

- **Control:** `Alt+R` reload Komorebi; `Alt+Shift+R` reload AHK; `Alt+Shift+P` pause Komorebi; `Alt+Shift+I` toggle hotkeys.

- **Focus:** `Alt+H/J/K/L` left/down/up/right; `Alt+Shift+[` / `Alt+Shift+]` cycle focus; `Alt+[` / `Alt+]` cycle the stack; `Alt+;` unstack.

- **Move:** `Alt+Shift+H/J/K/L` left/down/up/right; `Alt+Shift+Enter` promote; `Alt+Arrow` stack in that direction.

- **Resize:** `Alt+U/P` decrease/increase width; `Alt+I/O` decrease/increase height.

- **Window state:** `Alt+V/Y` flip horizontally/vertically; `Alt+Shift+Space` float; `Alt+F` monocle; `Alt+M` minimize; `Alt+X` close.

- **Workspaces:** `Alt+1–7` focus on numbered workspace; `Alt+Shift+1–7` move the focused window to the numbered workspace.

### YASB

- I split the top bar into separate left, center, and right bars on every monitor.
- The left shows Komorebi controls and the active window, the center holds the clock and quick launcher, and the right contains media, network, and system controls.
- `Ctrl+Alt+S` expands the system resource widgets, showing CPU and GPU usage along with the memory usage.
- `Alt+Space` (bound to `Ctrl+Alt+Space` by AHK) opens up a quick launch menu to open other applications on your device. Note that this replaces the default Windows context menu that shows up on Alt+Space.
- The Nerd Fonts option in the YASB installation is a requirement.

## Custom Scripts
- Most of these probably aren't of use to anyone else but if I'm backing up my configs I might as well include them.
- tsukihime just opens up Tsukiweb (https://github.com/requinDr/tsukiweb-public) along with the VNDB page for Tsukihime and a walkthrough for the game.
- mokuro opens up Mokuro reader (https://github.com/Gnathonic/mokuro-reader) in a browser.
- yt-jp opens up a Firefox window in a container (https://github.com/mozilla/multi-account-containers) and (https://github.com/honsiorovskyi/open-url-in-container) that I have set up for my alternate Google account where the language settings are all in Japanese and I have NihongoTube (https://www.nihongotube.app/) on by default.

## Notes about my machine that may explain some oddities:
- I use Git Bash as my main shell, switching to PowerShell when I run into something that requires a Windows-native shell. (I know it's inefficient, but I'm too used to Bash to change.)
- I have Caps Lock remapped to F13 (normal caps lock is on another keyboard layer).
